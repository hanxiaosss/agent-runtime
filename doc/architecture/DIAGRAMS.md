## 图3: 事件处理流程

```
┌─────────────────────────────────────────────────────────────────────┐
│  Event Processing Flow                                               │
└─────────────────────────────────────────────────────────────────────┘

  Agent Action
       │
       ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  1. Adapter 接收 Hook                                        │
  │     └─ CopilotAdapter.handlePreToolUse()                     │
  └──────────────────────────────────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  2. 转换为统一事件                                           │
  │     └─ UnifiedEvent { type: 'tool.before', ... }             │
  └──────────────────────────────────────────────────────────────┘
       │
       ▼
  ┌──────────────────────────────────────────────────────────────┐
  │  3. Event Bus 发布                                           │
  │     └─ eventBus.publish(event)                               │
  └──────────────────────────────────────────────────────────────┘
       │
       ├──────────────────────┬──────────────────────┐
       │                      │                      │
       ▼                      ▼                      ▼
  ┌──────────┐         ┌──────────┐         ┌──────────┐
  │ Policy   │         │ Trace    │         │ Plugins  │
  │ Engine   │         │ Store    │         │          │
  └──────────┘         └──────────┘         └──────────┘
       │                      │                      │
       └──────────────────────┼──────────────────────┘
                              │
                              ▼
                  ┌──────────────────────┐
                  │  4. 返回决策         │
                  │     └─ allow/deny    │
                  └──────────────────────┘
                              │
                              ▼
                  ┌──────────────────────┐
                  │  5. Feedback Loop    │
                  │     └─ Agent 调整    │
```
