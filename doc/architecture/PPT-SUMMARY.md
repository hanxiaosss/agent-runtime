## Slide 2: 问题背景

### AI Agent 生态碎片化

```
┌─────────────────────────────────────────────────────────────┐
│  当前状况                                                    │
│                                                              │
│  Claude Code ────── 独特的 Hook 协议                        │
│  Copilot ──────────── 不同的 Hook 协议                      │
│  Qoder ────────────── 又一种 Hook 协议                      │
│  Codex CLI ────────── 完全不同的协议                        │
│  Trae ─────────────── 最小化的协议                          │
│                                                              │
│  问题：                                                      │
│  • 每个 Agent 都有自己的事件模型                             │
│  • 策略无法跨 Agent 复用                                     │
│  • 追踪数据格式不统一                                        │
│  • 难以统一监控和管理                                        │
└─────────────────────────────────────────────────────────────┘
```

## Slide 8: 策略引擎

### 声明式 YAML 策略

```yaml
# 示例：保护敏感文件
name: protected-files
rules:
  - name: block-env
    when: code.before_modify
    match:
      - field: filePath
        pattern: "**/.env"
    action: deny
    feedback: "Environment files are protected"
```

## Slide 9: 数据流

### 完整的事件处理流程

```
┌─────────────────────────────────────────────────────────────┐
│  1. Agent 触发 Hook                                          │
│     └─ Copilot: PreToolUse                                  │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  2. Adapter 转换事件                                         │
│     └─ 统一事件: { type: 'tool.before', ... }               │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  3. Event Bus 发布                                           │
│     └─ 通知所有订阅者                                        │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  4. Policy Engine 评估                                       │
│     └─ 返回决策: allow / deny / warn                        │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  5. Trace Store 记录                                         │
│     └─ 写入 JSONL 文件                                       │
└─────────────────────────────────────────────────────────────┘
                            │
                            ▼
┌─────────────────────────────────────────────────────────────┐
│  6. Feedback Loop                                            │
│     └─ 返回决策给 Agent                                     │
└─────────────────────────────────────────────────────────────┘
```
