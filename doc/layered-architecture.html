📊 四层对比：速度 vs 能力 vs 成本

层级 检测方式 速度 成本 适用场景 典型用例
Command Hook 字符串模式匹配 < 10ms 零 高频、确定性检查 rm -rf, DROP TABLE, .env 修改
Prompt Hook LLM 语义理解 1-3s ~$0.04/月 低频、需要判断力的检查 shutil.rmtree('/'), 隐蔽密钥泄露, API breaking change
Semantic Hook 7 维度匹配 < 50ms 零 项目特定规则 禁止修改 src/core/**, 只允许特定 MCP 操作
Git Hook 提交前检查 < 100ms 零 代码质量 + 提交规范 代码格式检查, commit message 规范, 敏感信息扫描

Agent Runtime v0.2.0 | 四层防御体系：Command Hook (高速拦截) → Prompt Hook (深度分析) → Semantic Hook (项目规则) → Git Hook (最终防线)

💡 最佳实践：Command Hook 过滤 99% 明显问题，Prompt Hook 兜住漏网之鱼，Semantic Hook 执行项目规范，Git Hook 确保提交质量
